\# Definition of Done — Sprint 1



Una historia de usuario o tarea se considerará terminada cuando cumpla las siguientes condiciones:



\- \[ ] Cumple los criterios de aceptación acordados.

\- \[ ] El código o documento corresponde al alcance de la tarea.

\- \[ ] Los cambios han sido revisados por el responsable designado.

\- \[ ] Las pruebas correspondientes se han ejecutado y sus resultados son satisfactorios.

\- \[ ] No se conocen errores críticos pendientes relacionados con el cambio.

\- \[ ] Los archivos y cambios están registrados en Git mediante commits descriptivos.

\- \[ ] Los cambios se han enviado mediante un Pull Request hacia la rama `developer`.

\- \[ ] El Pull Request cuenta con la revisión y aprobación requeridas.

\- \[ ] La integración se realiza mediante un merge commit, de acuerdo con las reglas del repositorio.



\## Aplicación



Esta definición se utilizará como referencia para revisar las historias y entregables del Sprint 1 de CheckU.
